# Los Andes Inmobiliaria

Sistema de gestión y operaciones de Los Andes Inmobiliaria, desarrollado con Next.js (App Router), React, TypeScript y Tailwind CSS.

## Scripts disponibles

- `npm run dev`: Inicia el servidor de desarrollo local con soporte Turbopack.
- `npm run build`: Genera la compilación para producción con verificación de tipos.
- `npm run start`: Inicia la aplicación en modo de producción.
- `npm run lint`: Ejecuta el análisis de código con ESLint.
